# The Readme!

So I decided to make an entry into Google x Kaggle's Agentic AI Capstone.
And getting there is... rough.

My capstone idea is this: An agentic system whose goal is to do all the things necessary in order to win the "Agents Intensive - Capstone Project". Including:

* Read the desired outcome to understand what it needs to do
* Read all the documentation of the course to know what it is we went over to know what to use
* Write the documentation and code necessary to complete the course requirements
* Write a script for the 3-minute YouTube video

So, that's what this is.

## First pass: Beta-v0.0001-do-not-use!

Since this is Google, I figured I'd use Google's Gemini in order to complete this.

I guess I front-loaded too much onto it, and it didn't have the context necessary to really "get" what I was going for.
The first thing it suggested was an *actually good idea*: the "Multi-Agent Financial Insight System".
I would suggest this for anybody who wants to do a normal project, but I'm nor doing a normal project.
I'm doing a meta, recursive project, that showcases... something.
I'm not sure yet.
